# Task1 打卡：我的第一个工具 Agent（第 1–2 章）

## 验证什么
验证 Deep Agent 完整调用链：模型请求工具 → Python 函数执行 → ToolMessage 返回 → 模型生成最终回答；并用确定性对照验证自定义工具结果的正确性，以及空输入 / 超长输入下的边界行为。

## 改了什么
1. 主应用：`agentseek create deepagents/content-builder`（Windows 原生环境）
2. 环境适配：嵌入式 SeekDB（pylibseekdb）仅支持 Linux，原生 Windows 无法启动后端。改 `.env` 为 `SEEKDB_EMBED=false` + `METADATA_DB_BACKEND=sqlite` + `METADATA_DB_URL=sqlite+aiosqlite:///./agentseek_metadata.db`，后端正常启动（doctor 16 项全绿，course-check 14 passed）
3. 新增自定义工具 `count_words`（`src/content_builder_deepagent/lesson_tools.py`），并在 `agent.py` 的 `tools = [read_source, save_report, read_report, save_preference, count_words]` 中注册

## 实际结果
- 最小实验 `template: passed (offline)`；课程自检 `course-check`：14 passed
- 主应用真实运行：Agent 完成 6 步任务（read_source×3 → write_todos → 起草 → save_report → read_report），工具卡片全部"完成"，报告落盘 `blogs/course/post.md`
- `count_words` 完整调用链：网页指令"read_report 读报告 + count_words 统计" → 两个工具卡片均完成 → 最终回答"590 个英文单词、0 个汉字、8 个数字，总计 ≈ 598"
- **确定性对照**：本地直接调用 `count_words` 统计同一文件：590 英文单词 / 8 数字 / ≈598 —— 与模型回答完全一致，证明工具真实执行且模型如实转述返回值
- 边界测试：空输入 0/0/0；纯空白 0/0/0；5000 字符长文本 1000 词；混合文本 100 汉字+50 词+10 数字，计数均正确
- 会话持久化：重启后端后通过 thread URL（`/?thread=...`）恢复同一对话，SQLite checkpointer 生效

## 证据与解释
- **请求→执行→返回**：模型在 `tool_calls` 中发出 `{name, args, id}` → 框架实际运行对应的 Python 函数 → 结果装入 `ToolMessage`（携带相同 `tool_call_id`）返回模型 → 模型继续决策直至生成最终回答
- **组件映射**：
  - 模型：`agent.py` 中 `init_chat_model(DeepSeek-V3.2)`，`.env` 配置 SiliconFlow OpenAI 兼容接口
  - 工具：`lesson_tools.py` 中 `@tool` 装饰的函数，注册于 `agent.py` 的 tools 列表
  - Middleware：`TodoListMiddleware`（待办规划）+ `MemoryMiddleware`（注入 AGENTS.md 与偏好）+ Skills / PatchToolCalls
  - Backend：`FilesystemBackend(virtual_mode=True)` + agentseek-api SQLite checkpointer（本机适配）
- **证据文件**：`blogs/course/post.md`、course-check 输出、边界测试输出、网页工具卡片截图、thread URL 恢复记录
